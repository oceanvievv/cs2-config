# cs2-config

Создание, обновление, переименование и применение профилей CS2 через один portable EXE.
Интерфейс Spectre.Console на английском, имена профилей могут быть на любом языке.

[Скачай cs2-config.exe](https://github.com/oceanvievv/cs2-config/releases/latest/download/cs2-config.exe)
и запусти из папки с правом записи. Нужна Windows 10/11 со штатными Windows PowerShell 5.1
и .NET Framework 4.8. SDK, PowerShell 7 и установка дополнительных компонентов не нужны.

Выбирай пункты стрелками и подтверждай Enter. Ввод текста или номера фильтрует список.
Back возвращает на один экран, Back to main menu — в главное меню.
Профиль всегда выбирается явно.

## Применить профиль

Закрой CS2, войди в Steam и выбери Apply profile. Выбери профиль, проверь параметры
экрана и нажми Apply. View all settings открывает полный список настроек.
Параметры запуска вставь в Steam → CS2 → Свойства → Общие → Параметры запуска.

Предварительный запуск CS2 не требуется для подготовки файлов. Если частота превышает
доступную при заданном разрешении, используется максимальная с сообщением об изменении.
Профиль остаётся прежним. Пропуски и ошибки показываются отдельно; после запуска проверь игру.

## Изменить конфиг

Настрой CS2 и выйди из игры. Create profile создаёт профиль, Update profile обновляет
выбранный профиль после просмотра изменений. Rename config и Rename profile переименовывают
конфиг или профиль с сохранением настроек. Имена папки и репозитория остаются прежними.

Для переноса достаточно cs2-config.exe: профили встроены в него. Если рядом есть
profiles.json, данные читаются из него. Сохранение и переименование обновляют встроенные
данные. После изменений загрузи обновлённый файл в свой репозиторий и скачай его на другом ПК.
