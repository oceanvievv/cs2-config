# cs2-config

Инструмент для создания, сохранения и установки конфига CS2.

#### Какие настройки поддерживаются

- Игровые конфиги (autoexec, кастомные)
- Прицел
- Параметры запуска
- Настройки видео
- Копия облачных настроек (чувствительность мыши, прицел, бинды и т.д.)
- Настройки, привязанные к компьютеру (радар, fov, громкости и т.д.)

## Создание конфига на твоем компьютере

[Скачай установщик](https://github.com/oceanvievv/cs2-config/releases/latest/download/setup.cmd)
и запусти его. Установщик создаст папку с конфигом **в папке, где был вызван скрипт**:

```
cs2-config\
   apply-config.cmd // Скрипт применения твоих настроек
   apply-config-using-console.txt // Запасной вариант применения через консоль CS2, если скрипт не может отработать
   
   update-config.cmd // Скрипт обновления твоих настроек
   .gitattributes // Служебный файл: без него скачанный apply-config.cmd не запустится
   
   cfg\ // Игровые конфиги
   video\ // Разрешение экрана, частота обновления, качество картинки и т.д.
   machine\ // То, что Steam Cloud не переносит: радар, fov, громкости, размер HUD и т.д.
   cloud-backup\ // Копия того, что обычно хранится в Steam Cloud: чувствительность мыши, прицел, бинды и т.д.
   
   README.md // Инструкция
   README.ru.md // Инструкция на русском языке
```

Папку можно утащить на флешку или [выложить на GitHub](#конфиг-в-облаке) для установки конфига на другом компьютере.

## Обновление конфига

Для обновления конфига после изменений в игре запусти `update-config.cmd`.

Если конфиг уже выложен на GitHub, залей содержимое папки заново —
см. [Обновление конфига в облаке](#обновление-конфига-в-облаке).

## Установка конфига на другом компьютере

Есть 2 способа установки конфига в зависимости от того, как ты будешь его хранить:

1. [Конфиг в облаке](#конфиг-в-облаке). Перейди в свой репозиторий и используй ссылку из README для скачивания файла применения конфига

2. Папка с конфигом на флешке: перенеси свою папку с конфигом на другой компьютер и запусти `apply-config.cmd`

   > Если скрипт не сработает, скопируй содержимое `apply-config-using-console.txt` в консоль CS2. Применятся только твои базовые конфиги и прицел. 

## Конфиг в облаке

### Создание конфига в облаке
1. Авторизуйся на [github.com](https://github.com)
2. Создай публичный репозиторий (например `cs2-config`)
3. На открывшейся странице нажми **uploading an existing file**
4. Перетащи на страницу содержимое папки cs2-config
5. Нажми **Commit changes**

### Обновление конфига в облаке
1. Перейди в репозиторий своего конфига
2. Нажми `Add file` и выбери `Upload files`
3. Перетащи на страницу содержимое папки cs2-config
4. Нажми **Commit changes**
