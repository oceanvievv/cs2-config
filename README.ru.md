# cs2-config

Создание, обновление и применение профилей настроек CS2 через CMD.
Интерфейс на английском, имена профилей могут быть на любом языке.

## Создать конфиг

[Скачай setup.cmd](https://github.com/oceanvievv/cs2-config/releases/latest/download/setup.cmd) и запусти из доступной для записи папки. Войди в Steam,
настрой CS2 и выйди из игры. Укажи имя профиля, проверь настройки и папку
сохранения, выбери **Create profile**. При необходимости укажи свои пути Steam и CS2.

В папке появятся `profiles.json`, три CMD-файла, README и папка `console`.
Заданных заранее имён и профиля по умолчанию нет.

В стандартной консоли Windows пункты меню и строка ввода закреплены внизу окна. Длинные экраны
прокручиваются колёсиком или Page Up / Page Down. При возврате в раздел позиция
прокрутки сохраняется. Ctrl+V вставляет текст в строку ввода.
Если список профилей или аккаунтов не помещается, Tab / Shift+Tab переключает страницы пунктов.

## Применить профиль

Закрой CS2, войди в нужный аккаунт Steam и открой `apply-config.cmd`. Выбери
**Apply profile**, затем профиль, проверь настройки и нажми **Apply**.
Параметры запуска вставь в **Steam → CS2 → Свойства → Общие → Параметры запуска**.

Папки настроек создаются при необходимости. Предварительный запуск игры для этого
не требуется. Если частота выше доступной для выбранного разрешения, утилита
использует максимальную и сообщает об изменении. Профиль остаётся прежним.
Недоступное разрешение пропускается; независимые настройки продолжают применяться.

Успех означает запись и проверку файлов. После запуска CS2 проверь результат
в игре. Пропуски и ошибки выводятся отдельно.

## Обновить настройки

Измени настройки игры или параметры запуска Steam, выйди из CS2 и открой
`update-config.cmd`. Выбери профиль, проверь изменения и нажми **Save changes**.
Другие профили не меняются. Предыдущие версии и резервные копии не сохраняются.

Для нового профиля используй **Create profile** или созданный `setup.cmd`.
`Back` возвращает на один экран, `Back to main menu` — в главное меню.

## Переименовать конфиг

Чтобы переименовать конфиг, выбери **Rename config** в главном меню и введи новое имя.
Можно использовать кириллицу и пробелы. `0` возвращает назад. Название обновится
в `profiles.json`, CMD-файлах, заголовках README и окна. Имена профилей, папки
и GitHub-репозитория останутся прежними.

Для переименования профиля выбери **Rename profile**, затем профиль и новое имя.
Настройки сохранятся, имя должно отличаться от имён остальных профилей.
Файл консольных команд и ссылки в README обновятся; пользовательские инструкции
в README сохранятся.

## Перенести конфиг

Перенеси всю папку или один `apply-config.cmd`: в него встроены все профили.
Если рядом есть `profiles.json`, настройки читаются из него. После обновления
опубликуй содержимое папки заново и скачай свежий CMD на другом ПК.

На GitHub открой свой репозиторий, выбери **Add file → Upload files**, загрузи
содержимое папки и нажми **Commit changes**. Автоматической публикации нет.

Если CMD недоступен, открой README конфига и файл команд нужного профиля.
Вставляй команды в консоль CS2 небольшими частями. Поддерживаются прицел, мышь,
звук и управление.

Подробности и команды проверок: [English README](README.md).
